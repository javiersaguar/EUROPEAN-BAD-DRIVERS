# European Bad Drivers Index

Does a territory look different when you measure road deaths, injury crashes or minor collisions?
This project investigates that question using official sources and explicit denominators.
An experimental composite cannot establish whether a country's residents are inherently good or bad drivers.

Construction proceeds through an evidence-based feasibility audit, a Spain pipeline, an index laboratory,
a comparable European extension and a conditional-severity experiment.

Author: Javier Saguar. Code is MIT licensed; source datasets retain their own reuse conditions.
